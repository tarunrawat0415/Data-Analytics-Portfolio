# Amazon Sales Performance Dashboard

## Project Overview

This Power BI dashboard provides an interactive analysis of Amazon sales performance for 2023–2024.

The dashboard helps analyze revenue, orders, order status, product categories, sales performance by location, ratings, and discounts.

## Key Metrics

- Total Revenue: 16.08M
- Total Orders: 725
- Analysis Period: 2023–2024

## Dashboard Features

- Monthly Sales Trend
- Order Status Breakdown
- Revenue & Orders by Product Category
- Sales Performance by City & State
- Average Rating & Discount by Category
- Year-wise Analysis using interactive filters

## Tools & Technologies

- Power BI
- Data Visualization
- Data Analysis
- Microsoft Bing Maps

## Key Insights

- Compared monthly sales performance across 2023 and 2024.
- Analyzed order status distribution.
- Compared revenue and order volume across product categories.
- Analyzed sales performance across different locations.
- Compared average ratings and discounts across categories.
